Local network test guide

Commands, permissions, and expected chat output for the Docker Velocity stack (hub + minigame). Join localhost:25565 with vanilla Minecraft 26.2.

Setup aegis harbor gatekeep loom spotlight cull ledger amber tether cairn

Setup checklist

  1. ./scripts/use-java.sh ./gradlew build
  2. cp testbed/.env.example testbed/.env (optional overrides)
  3. ./testbed/scripts/sync-plugins.sh
  4. docker compose -f testbed/docker-compose.yml up -d
  5. Join localhost:25565 (plain vanilla spawn on hub). Start the second backend only when needed: docker compose -f testbed/docker-compose.yml --profile minigame up -d, then /server minigame.

Give yourself op on hub for permission defaults that use op. Velocity permissions for harbor/aegis may need a permissions plugin or LuckPerms later; for MVP, many checks are console-friendly or player-facing only.

Honest status: MVP plugins. Docker configs under plugin-config/ already use mariadb / redis. Run sync-plugins.sh before Compose. Mineflayer joins as protocol 26.1 via ViaBackwards. Full write-up: docs/LOCAL-NETWORK.md.

aegis Paper + Velocity

Network bans, mutes, warnings, SQL audit, Redis sync, optional Discord webhook.

CommandPermissionDefaultExpected output / effect
/aegis ban <player> [duration] <reason> aegis.ban op Chat: BAN applied to <player>. Target kicked if online. Banned UUID cannot rejoin hub/minigame while active. Duration examples: 30s, 12h, 7d. Omit duration for permanent.
/aegis unban <player> aegis.unban op Revoked or No active punishment.
/aegis mute <player> [duration] <reason> aegis.mute op MUTE applied to <player>. Muted player chat is cancelled; they see the muted MiniMessage template.
/aegis unmute <player> aegis.unmute op Revoked or No active punishment.
/aegis warn <player> <reason> aegis.warn op WARN applied to <player>. Stored in history only (no kick).
/aegis history <player> aegis.history op Lines like BAN by Admin: cheating [active], or No history.

Also requires base permission aegis.use (op) to see the command on Velocity.

Manual test plan

  1. Two clients (or one client + Mineflayer bot).
  2. Ban bot with /aegis ban Bot1 1h testing.
  3. Confirm bot cannot reconnect.
  4. /aegis unban Bot1 then reconnect succeeds.
  5. Mute yourself, send chat, confirm block message; unmute.

harbor Velocity

Priority queues and backend health routing when servers are full or unhealthy.

CommandPermissionExpected output
/harbor leave (player) Left queue or Not queued.
/harbor status [server] (anyone) Queue hub: N | healthy=true/false (server defaults from config).

Priority permissions (config-driven): harbor.priority.vip (10), harbor.priority.staff (50).

Manual test plan

  1. Fill a backend or mark it unhealthy so players queue.
  2. Join with a normal bot and a VIP-permission player; VIP should leave queue first when a slot opens.
  3. /harbor status hub shows queue size.

gatekeep Velocity

Connection rate limiting by address. No player command in the MVP.

BehaviorConfigExpected effect
Burst connects from same address max-attempts, window-seconds Extra attempts denied with MiniMessage deny-message (default: too many connections).

Manual test plan

  1. Run Mineflayer with a high BOT_COUNT quickly from one host.
  2. Confirm later bots are kicked/denied once the window limit is hit.
  3. Wait for the window and confirm joins work again.

loom Paper

Cross-server inventory sync with transfer locks.

Command / eventPermissionExpected output / effect
/loom loom.use loom sync is active.
Quit then join other Paper server (passive) Inventory restored from SQL. If lock held: kick Data sync in progress.

Manual test plan

  1. On hub, put unique items in inventory.
  2. Switch to minigame (both need loom + shared DB).
  3. Confirm items match. Rapid reconnect during sync should hit the lock kick.

spotlight Paper

Lag attribution by loaded chunk entity/hopper cost.

CommandPermissionExpected output
/spotlight spotlight.use to see command; spotlight.scan to run Header Top lag chunks: then lines like world 0,0 entities=12 hoppers=3 score=36.

Manual test plan

  1. Spawn many entities or place hoppers in one chunk.
  2. Run /spotlight as op and confirm that chunk ranks near the top.

cull Paper

Per-chunk mob limits and periodic cleanup.

Command / behaviorPermissionExpected output / effect
/cull cull.use cull max per chunk: <n> (from config).
Creature spawn over limit (passive) Spawn cancelled. Periodic task removes oldest non-player entities when over limit.

Manual test plan

  1. Set a low max-entities-per-chunk and reload/restart.
  2. Spawn mobs past the limit; extras should not appear / get culled.

ledger Paper

Vault-compatible economy with a SQL ledger. Vault soft-depends if present.

CommandPermissionExpected output
/bal [player] ledger.use <name> balance: <amount>.
/pay <player> <amount> ledger.use Paid <amount> or Insufficient funds.
/ledger give <player> <amount> ledger.admin Deposited <amount> or No permission.

Manual test plan

  1. /ledger give Steve 100 as op.
  2. /bal Steve shows 100.
  3. /pay Alex 25 from Steve; both balances update.

amber Paper

Async world snapshots with retention.

CommandPermissionExpected output
/amber snapshot [world] amber.use to see command; amber.admin to run Snapshot saved: <file> or world/error message.
/amber list amber.use + amber.admin One filename per line, or No snapshots.

Manual test plan

  1. /amber snapshot world then /amber list.
  2. Create more than retain snapshots; oldest should be pruned.

tether Paper

Discord account linking and chat bridge. Needs a Discord bot token in config.

Command / flowPermissionExpected output
/tether link tether.use In Discord, send: !link <code>.
Discord !link <code> (Discord) Discord replies Linked to Minecraft account.
Game chat / Discord chat (passive) Bridged messages when token + channel-id are set.

If require-link-to-join is true, unlinked players are kicked: Link Discord with /tether link.
